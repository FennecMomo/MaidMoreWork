# 版本更新记录

> **记录规则：只有作者明确要求"记录到本文档"时，才允许新增/修改条目。**
> 未明确指示时，任何改动一律不得写入本文档（包括 bug 修复、机制调整、临时诊断、内部重构等）。

> **版本号规则：**
> - 每向本文档新增一条记录 → 版本号第三位 +1（如 0.1.1 → 0.1.2 → 0.1.3 …）；
> - 每发布一次版本 → 版本号第二位 +1，第三位归零（如 0.1.x → 0.2.0 → …）；
> - **模组版本号与本文档同步**：每次版本号变动时，同步更新 `gradle.properties` 的 `mod_version` 与 `docs/INDEX.md` 顶部的版本行。
