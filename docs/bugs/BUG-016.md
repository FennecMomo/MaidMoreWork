# Bug #16：isInventoryFull 检测不触发存款

> 状态：已修复 | 发现：2026-07 | 修复：已应用

## 问题描述
女仆挖矿后，物品能塞进背包，但背包满了之后永远不会触发向矿井方块（MineBlockEntity）的存款操作。

## 根因

### 日志证据
```
MiningBehavior: inventory check total=36 empty=4 maid=4   （大背包）
MiningBehavior: inventory check total=36 empty=27 maid=5  （无背包）
MiningBehavior: inventory check total=36 empty=4 maid=4   （18秒后不变）
```

### 分析
- `inv.size()` 永远返回 **36**（MaidBackpackHandler 的物理总槽数）
- TLM 的 `ItemStacksResourceHandler`（`getMaidInv()`）**不执行背包等级限制**
- 无背包女仆实际只能用 **9 格**（BackpackLevel.EMPTY_CAPACITY=6 + 额外3格基础槽位），但代码遍历 36 格
- 结果：`emptyCount` 永远 > 0 → `isInventoryFull` 永远返回 false → 永远不触发存款

### TLM 背包等级常量
```java
// com.github.tartaricacid.touhoulittlemaid.item.BackpackLevel
EMPTY_CAPACITY  = 6   // 无背包
SMALL_CAPACITY  = 12  // 小背包
MIDDLE_CAPACITY = 24  // 中背包
BIG_CAPACITY    = 36  // 大背包
```

## 修复方案

### 核心思路
用 `getAvailableBackpackInv()` 替换 `getMaidInv()`，前者返回当前背包等级下的**可用槽位**。

### 已修改的方法（MiningBehavior.java 当前代码）

| 方法 | 状态 | 说明 |
|------|------|------|
| `isInventoryFull` | 已改为 `getAvailableBackpackInv()` | 检查背包是否满 |
| `addToInventory` | 已改为 `getAvailableBackpackInv()` | 往背包插入物品 |
| `tryRetrieveFromMineBlock` | 已改为 `getAvailableBackpackInv()` | 从矿井取物品回背包 |
| `depositToMineBlock` | 保留 `getMaidInv()` | 清理可能漏进不可用槽位的残留物品 |
| `hasScaffoldBlock` | 保留 `getMaidInv()` | 只读检查，不影响 |
| `hasTorchBlock` | 保留 `getMaidInv()` | 只读检查，不影响 |
| `tryPlaceScaffold` | 保留 `getMaidInv()` | 从背包取方块放置，应遍历全部槽 |
| `tryPlaceTorch` | 保留 `getMaidInv()` | 从背包取方块放置，应遍历全部槽 |
| `tryFillBelow` | 保留 `getMaidInv()` | 从背包取方块，应遍历全部槽 |
| `equipPickaxe` | 保留 `getMaidInv()` | 换装备，应遍历全部槽 |

### 判断原则
- "往背包插入/检查是否满" → 改用 `getAvailableBackpackInv()`
- "从背包提取/清理全部物品" → 保留 `getMaidInv()`

## 测试方法
1. 编译：`cd maidmorework && .\gradlew.bat compileJava`
2. 启动游戏，让女仆挖矿
3. 查看日志 `run-shared\logs\latest.log`，搜索 `inventory check total=`
4. 验证：无背包 maid 的 total 应 ≈ 9（而非 36）；大背包 maid 的 total 应 = 36；背包满后应出现 `inventory full=true`，随后应出现 `deposited item to mine block`

## TLM API 参考

```java
// MaidItemManager
ItemStacksResourceHandler getMaidInv()                          // 物理全部36槽（不受背包等级限制）
CombinedResourceHandler<ItemResource> getAvailableBackpackInv() // 当前背包等级下的可用槽位
CombinedResourceHandler<ItemResource> getAvailableInv(boolean)  // 全部可用库存（含护甲、手等）
CombinedResourceHandler<ItemResource> getAllInv()               // 所有库存
```
